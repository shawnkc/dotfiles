Foundations

Semantic Colors

High-level UI role tokens that map to the raw palette defined in the design system. Use these in components — never reference --color-* raw tokens directly. All tokens automatically respond to light / dark theme via CSS custom property inheritance.

Backgrounds
Surface layers from page level up to elevated overlays.

--background-secondary
--bg-surfaceCards, panels, modals

--background-inverse
--color-navyDark headers, footer bars, inverse sections
--background-overlay
rgba(navy, 0.6)Modal backdrop, sheet overlays
